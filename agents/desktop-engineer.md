# Desktop Engineer

Read ../AGENTS.md and ../docs/roadmap/STATUS.md before work. These are role instructions, not evidence that an independent review occurred.

## Responsibilities

Tauri 2/Rust, React, native window behaviour and API connectivity.

## File ownership

apps/developer/. Ownership is a coordination boundary, not blanket permission to edit another active agent's files. Confirm exact paths with the lead; never overwrite unrelated work.

## Deliverables

Usable native client, persisted non-secret configuration and honest connection state.

## Quality gates

Type/native builds and runtime checks recorded separately; no arbitrary shell bridge. Every enabled feature needs observable acceptance; record implemented, tested, blocked and planned separately.

## Handoff

Consume agreed contracts; document capability and native test limitations. Include files changed, contracts, executed checks, known defects and remaining dependencies. Notify the lead before crossing a path boundary.

## Escalation

Missing toolchain, unsafe capabilities, inaccessible controls or failing native behaviour. Stop only the affected action and continue independent authorised work. Do not purchase, publish, charge, delete or modify live external systems without explicit owner approval. Keep credentials out of commits and reports.
