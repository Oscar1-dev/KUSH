# Visual-first roadmap

## V0 — bundled starter
- Working source scaffold for responsive homepage (not runtime verified in this environment)
- Pointer-reactive atmospheric lighting and CSS orbit artwork
- Motion scroll parallax, marquee, typography and editorial sections
- Accessible reduced-motion fallback

## V1 — establish the brand
- Import actual KUSH logo, refine typography and colour system
- Create three alternative art-directed hero directions and choose one
- Build consistent navigation, responsive mobile menu, polished footer
- Add high-quality imagery/assets that we own or are licensed to use

## V2 — premium interaction
- Split sections into composable components
- Scroll-triggered entrance and transition choreography
- Magnetic interaction and pointer trails (desktop only)
- Page transitions, kinetic type and hover previews
- Optional dynamically loaded 3D hero scene with non-WebGL fallback
- Respect reduced motion and coarse pointer devices

## V3 — service and product presentation
- Services pages, portfolio case studies, clear availability states
- Product teaser pages without fake purchase buttons
- Working contact workflow with privacy-conscious handling
- Real content, SEO, performance and accessibility reviews

## V4 — platform integration
- Connect public content to the existing KUSH API where needed
- Add authenticated portal/checkout only after backend and compliance are ready
- Deploy on an explicitly approved free/paid platform

## Quality targets
- Test on low-end mobile and high-DPI desktop
- Keyboard-only navigation and reduced motion
- Core Web Vitals measurement; budget GPU and JS work
- No expensive animation on every pointer frame if avoidable
- No live payments, external resources, or public deployment without approval
